# 스포츠복지 플래너

지역별 스포츠강좌이용권 현황과 사용자 입력 목표를 비교하고, 출처와 가정을 담은 검토표를 출력하는 정적 웹 서비스입니다.

[공개 서비스 열기](https://cloudr1ng.github.io/sports-welfare-planner/) · 최초 Pages 배포: 2026-10-01 KST. 이용 권한이 있는 자료를 브라우저에서 선택해 사용합니다.

## 실행

Node.js 22 이상을 설치한 뒤 작업 폴더에서 실행합니다.

```powershell
npm ci
npm run dev
```

터미널에 나온 로컬 주소를 브라우저에서 엽니다. **기본 앱에는 공단 원본이나 실제 인원 자료를 넣지 않았습니다.** 화면의 `자료 불러오기`를 눌러, 이용 권한이 있는 CSV 또는 JSON을 선택합니다. CSV는 통계 기준 월, 출처 URL, 자료 범위를 입력해 확인합니다. 파일은 브라우저 메모리 안에서만 처리합니다. 새로고침하면 초기화됩니다.

현재 검증한 원본 이름은 `KS_AREA_ACCTO_SPORTS_VOUCH_PRCUSE_INFO_202607.csv`입니다. 개발자가 기획/검증 작업에서 보유한 원본은 Git 추적과 사이트 번들에서 제외합니다. 공개 빌드 전 검사는 원본의 행 식별자, 전체 파일 해시, 파일명을 포함한 비공개 자료 참조 여부를 확인합니다. 개발 담당자가 원본 CSV를 가지고 있지 않으면 실데이터 검증 절차를 수행할 수 없습니다.

## 기능

- 연도·시도·수급 구분별 지역 현황 필터, 검색, 정렬.
- 한 지역에서 목표 비율·월 단가·기간을 설정하는 시나리오 최대 3개.
- 계산식·가정·출처·기준 월·원천 행 ID를 담은 인쇄/브라우저 PDF 검토표.
- 결측·잘못된 값·중복 행을 표시하고 대상/수급 계산을 보류합니다.

목표 단가와 기간은 사용자 가정입니다. 산출 금액은 실제 필요 예산이나 집행액을 뜻하지 않습니다.

## 확인

```powershell
npm test
npm run test:ui
npm run build
```

공개 저장소의 `public-tests/`는 공식 데이터와 무관한 합성 입력으로 계산 경계와 오류 처리를 검사합니다. 실제 데이터 기반 단위·브라우저 테스트와 검증 문서는 로컬에 보관하며 공개 저장소에서 제외합니다. `npm run test:ui`는 해당 로컬 테스트와 이용 권한이 있는 원본 CSV, 설치된 Google Chrome이 있는 환경에서 실행합니다. 화면·PDF 시험 결과도 `test-results/`에 보관하며 Git에서 제외합니다. 빌드는 허용된 HTML·JS·CSS 파일만 포함하는지 검사하며, 로컬 원본 manifest가 있을 때는 실제 파일 해시도 검사합니다.

## GitHub Pages 배포

프로젝트 Pages 빌드는 저장소 경로에 맞는 Vite base가 필요합니다. 저장소에 연결된 뒤 수동으로 빌드할 때는 `.env.example`을 복사해 `.env`를 만들고 아래처럼 실제 저장소 이름으로 설정합니다.

```text
GITHUB_PAGES_BASE=/저장소이름/
```

```powershell
npm run build
```

`.github/workflows/pages.yml`은 사용자가 이 프로젝트를 GitHub 저장소의 `main` 브랜치에 올린 다음 실행할 Pages 배포 작업입니다. GitHub 저장소 Settings → Pages에서 배포 원본을 GitHub Actions로 지정해야 합니다. 배포 대상 저장소는 `CloudR1ng/sports-welfare-planner`입니다. 실제 배포 결과는 저장소 Actions와 Pages 설정에서 확인할 수 있습니다.

빌드 결과는 `dist/`입니다. 공식 데이터의 GitHub/Pages 공개 재배포 조건도 확인되지 않았으므로, 배포 빌드에는 실제 데이터가 들어가지 않습니다. 실제 수치, 캡처, 검토표를 공개하려면 먼저 자료별 이용조건을 확인해야 합니다.
